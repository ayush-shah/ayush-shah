I'm **Ayush Shah**, a **Solutions Engineer at Deuex**. Since 2021, I've worked as a **Software Engineer with its client [Collate](https://www.getcollate.io/)** on [OpenMetadata](https://github.com/open-metadata/OpenMetadata). Based in Mumbai, I build metadata ingestion and backend workflows for data discovery, governance, lineage, observability, and Context Center.

My public work includes [hundreds of merged pull requests](https://github.com/search?q=is%3Apr+author%3Aayush-shah+org%3Aopen-metadata+is%3Apublic+is%3Amerged&type=pullrequests) across the OpenMetadata organization. Here are three examples of the problems I've worked on:

## Selected engineering work

- **Cloud authentication and ingestion:** Added AWS RDS IAM authentication for [MySQL and PostgreSQL metadata ingestion](https://github.com/open-metadata/OpenMetadata/pull/11937), spanning connection handling, schema, service conversion, tests, and documentation.
- **Data lakes and data quality:** Added [manifest support and profiling fixes](https://github.com/open-metadata/OpenMetadata/pull/13017) for data lake ingestion, then [data-quality and profiler support](https://github.com/open-metadata/OpenMetadata/pull/14424) for Databricks Unity Catalog.
- **Backend reliability:** Added [validation and migration for ingestion pipeline configurations](https://github.com/open-metadata/OpenMetadata/pull/29566) and [parameterized SQL query construction](https://github.com/open-metadata/OpenMetadata/pull/24902) with regression coverage.

## Experience

- **Backend:** Python, Java, Dropwizard, Django, SQL, OpenSearch, and Elasticsearch.
- **Data and metadata:** Deep Snowflake experience; Databricks, BigQuery, Redshift, and data lakes. Metadata integrations across Tableau, Power BI, Airflow, Fivetran, OpenSearch Dashboards, and Kafka connections, including bootstrap servers and Schema Registry.
